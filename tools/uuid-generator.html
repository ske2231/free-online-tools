How to generate UUIDs

Enter how many UUIDs you need (up to 10,000), optionally toggle uppercase or hyphen-less output, and click Generate. Copy them all to the clipboard or download as a plain text file — one UUID per line — ready to import into a spreadsheet or script.

What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit label like 3f6b9c2a-7d1e-4f5a-9b3c-8e2a1d4f6b7c used to uniquely identify records in databases, API resources, distributed systems, and files. Version 4 UUIDs are randomly generated, and with 2^122 possible values, the chance of two colliding is effectively zero — you don't need a central authority to hand them out.

Are these UUIDs truly random?

Yes. Each UUID is generated with crypto.randomUUID() (with a secure fallback for older browsers), which uses your operating system's cryptographically secure random number generator. Generation happens entirely in your browser, so nothing is sent to a server or reused.
